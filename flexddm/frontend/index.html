Differential Evolution

Objective / G2 Binning

These quantiles define the response-time bins used by the G2 objective. They affect both simulation fitting and Fokker-Planck fitting when the FP objective is set to G2.

Fokker-Planck

Fokker-Planck uses the FP-readable functions in the selected model file. One-dimensional models use the compiled adaptive KFE solver when drift and boundary may vary over time but diffusion is constant. Time-varying or evidence-dependent diffusion falls back to the compiled transition solver because the KFE path represents diffusion as a scalar solve parameter.
